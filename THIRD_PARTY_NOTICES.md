## Installed dependencies

The source export contains `package-lock.json` and excludes installed dependencies, native binaries, and built UI assets. The lockfile identifies the resolved dependency versions and records their declared licenses. Refer to the license files distributed with each package for the applicable terms and notices.

The Mac app (`StreamDeckPlus.app`) is a binary distribution: it contains the built UI, the production dependencies listed above with their license files, the `node-hid` and `@napi-rs/canvas` native modules for its architecture, and Electron. This file ships inside the app (`Contents/Resources`) and is linked from **Settings ▸ About ▸ Licenses**, next to `NATIVE_NOTICES.txt` (generated by `scripts/native-notices.mjs` from the `@napi-rs/canvas` SBOM and `hidapi`'s license: Skia, FreeType, HarfBuzz, ICU, libpng, libjpeg-turbo, libwebp, zlib, expat and the Rust crates compiled into the canvas module), `LICENSE.electron.txt` and `LICENSES.chromium.html`. For any other distribution that includes built UI, icons, installed packages, or native binaries, inventory the components in that artifact and include their applicable licenses, notices, and source availability information.
